Construction

Ratios of the mark's own font size, so one definition serves every size. brand.mark in tokens.json generates these into CSS and Tokens.swift together. A component applies mark-bound, the generated utility; Swift reads Tokens.Mark.

TokenValue
--mark-bound-width 0.09em The letterforms' stroke weight at semibold
--mark-bound-height 1.05em Overshoots the cap height, so the bound is still a bar at 17px
--mark-bound-gap 0.18em Each side
--mark-bound-radius 999px A drawn rule, not a | glyph — the character sits on the baseline and reads as "l Stint l"

The bounds inherit currentColor, so the mark works on any ground from one definition. text-strong by default, text-muted where it recedes — a whole utility, not a shade, so the bounds follow.

Colour that means something
accent-default the running timer
success paid, saved, done
timer-warning runaway, overdue
danger something is wrong

Green marks the live, primary thing on a screen — in the app, the running timer. The test: could a user say in one short phrase what green means here, and would it be true of every green thing in view? It is a test, not a quota — the landing page's three ticks and its CTA are all green because all four are "what Stint does for you".

Green is a state channel — present tense, accruing right now. Success is an outcome channel — past tense, entry saved. Different categories, so different hues.

Focus rings stay neutral: a ring is constant and involuntary, and spending the accent there drowns the one signal it exists for.

The full palette and its derivation is deriving-colour.md.

Four planes
bg-recessed header, timer bar
bg-base rail, dock
bg-primary content column
bg-elevated cards, + shadow-card

Depth increases toward what is being read, an even ΔL 0.035 a step. A card darker than the surface under it reads as a hole.

The frame rises toward the card in both themes — a near-black card on a blacker frame, or a white card on a grey one. Only the ink inverts.

Eight hues at fixed L 0.70, C 0.11, varying only hue and skipping the accent's zone. Fixed lightness and chroma are what stop a chip out-brighting the running timer.

Colour belongs to the client, not the project — it answers whose work is this?, which is the question a calendar and a heatmap keep asking. The project's name answers which piece?. Internal work gets no colour.

Charts use the two dedicated categoricals on the blue/orange axis, the only axis dichromats retain — the eight are separable enough for labelled chips, where text carries the identity, and not for a chart.
