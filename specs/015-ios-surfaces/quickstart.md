# Quickstart: The timer outside the iPhone app

On an EAS Build simulator build of Stint Local (`docs/mobile.md`, Outside
the app), signed in to the local stack:

1. Start the timer in the app: the Live Activity shows it on the lock screen
   and in the Dynamic Island.
2. Lock the phone and press Stop on the Live Activity: it goes, and the web
   shows the entry stopped.
3. Add the widgets: they show Start with the most recent task. Press Start:
   the widget runs at once, and the Live Activity starts.
4. In Shortcuts, run Stint's Stop: Siri says it stopped.
5. With the web server stopped, press Start: the widget names why after 10
   seconds.
