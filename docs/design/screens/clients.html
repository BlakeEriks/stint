  • A hint replaces an unset value, never accompanies a set one. "Defaults to your standard rate" is useful while the field is empty and is clutter once it is filled.

Colour

Only clients have a colour, and it answers one question wherever it appears: whose work is this? The calendar, the entry list and this list all read the same value through useProjectColors().

  • A closed set, not a colour input. One lightness and one chroma for all eight, well under the accent on both, so a chip can never out-bright the running timer. An arbitrary colour could.
  • None is a real choice, first in the row. Internal work has no client and so no colour, and that is a state to pick, not an absence to explain.
  • Selection is a ring, never a checkmark — a glyph drawn on the colour has to contrast against all eight.
Add and edit

One form for both, differing only in which request it issues, so the field set and its validation cannot drift. It renders as a page and inside a dialog — created mid-flow from the project dialog — so what happens after a save is passed in: the page goes to the new client, the dialog hands it back to the select that asked.

Check on save · Cancel is the only action with no glyph
  • Cancel carries no icon. It undoes the intent rather than performing one, and a glyph beside it would give a dismissal the same weight as the save it sits next to.
  • Saving swaps the check for a spinner and the label to "Saving…", which is what the entry and project dialogs already do — the button keeps its shape while the request is out.
  • Submit is disabled until the name is non-empty, and it is the only required field — everything else has a defined fallback.
  • An empty optional field saves null. The columns are nullable and the schema rejects a blank email, so an empty string is a validation error rather than "unset".
Where the rate goes

A client's rate is the middle link. resolveRate() in @stint/core reads them in order, and the first non-null wins — 0 included, which is why the chain coalesces on null rather than on truthiness.
