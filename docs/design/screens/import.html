  • The preview is what gets written. Confirm sends the same file and the server derives the rows again with the same function, so nothing the page holds can make the write differ from what was read.
  • The zone is asked for, defaulting to this browser's. An export's times are wall clock in the zone of the account that made it, and a contractor who travels is often somewhere else. Start times are shown so a wrong zone is visible before anything is written.
  • The rate is this app's, never the export's amount. Each row resolves through resolveRate like any entry. A row with nothing to resolve reads "No rate" in the danger channel — invoicing refuses unrated work, so it is a blocked invoice, not a detail.
  • A row with no end time is shown and not written. An import never starts a timer and never invents an end.
  • Projects and clients match by name, ignoring case and surrounding spaces. One that does not exist is named in the summary before it is created.
  • Import is the one accent on the screen beside the running timer — the action the screen exists to complete.
  • An unreadable file says so under the picker, in neutral text, with "Nothing was imported." Nothing below it renders.
