  • A region with nothing in it is not drawn. Clients appear only when the file names any, overlaps only when it has any. Nothing inside the panel is a card; an inset rule is the only edge between regions.
  • One line says what confirming adds: entries, new clients, new projects, and rows that won't import. Money is Home's — it is there the moment the import lands.
  • The line opens with the first and last times, so a wrong zone is visible before anything is written.
  • The preview is what gets written. Confirm sends the same file with every choice made here — exclusions, rates, dates and colours — and the server derives the rows again with the same function, so nothing the page holds can make the write differ from what was read.
  • Every client in the file has a row, with the hours it will receive. Work with no client has none: it is never on an invoice.
  • "Invoiced through" is per client, because clients are billed on their own cycles, and it is optional. Rows on or before a client's date import as invoiced elsewhere: still earned, never unbilled, never on an invoice here. A single date would either strand unbilled work or offer billed work for a second invoice, and nothing changes it after the import.
  • A client the import creates gets its rate here, so invoicing works without a trip to each client's page. Empty falls through to your default; with no default the field reads "rate" and the client's work imports unrated. An existing client's rate is shown, not edited.
  • A new client's colour is the swatch leading its name: pressed, it opens the closed set of eight and none. None is the default. Colour moves no number, so choosing one does not re-read the file; it is sent with the confirm. An existing client's swatch is only its mark — its colour is changed on its own page.
  • Every overlap past the 60-second grace period is listed, longest first — against work in Stint or between two rows of the file, and the row says which. The row is the entry that started later: it began inside the other, so it is usually the one to drop.
  • The fix is Exclude: the listed row stays out of the import and what it overlaps stands. Nothing already in Stint is touched. An excluded row dims in place, reads "won't import", and offers Undo. The first five show; Exclude all is the answer to more.
  • An overlap left alone imports as it is and waits in the inbox. Work invoiced elsewhere never reaches the inbox, so for that history this list is the one place to settle it.
  • Projects and clients match by name, ignoring case and surrounding spaces.
  • Import is the one accent on the screen beside the running timer — the action the screen exists to complete.
  • After the import, the preview gives way to what it did: how many entries, into which clients, and how many were already here. Unrated entries come first, in the danger channel, with Set a rate — the client's page when the import touched one client, Settings otherwise — because invoicing refuses them. Then Open the calendar.
  • "Import them as billable" appears under the line only when the export marks every row not billable — Toggl's free plan does that to all of them.
  • A file with nothing new reads "Nothing new in this file", and the button reads Nothing new, disabled.
  • An unreadable file says so under the picker, in neutral text, with "Nothing was imported." Nothing below it renders.
